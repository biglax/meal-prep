# Meal Prep — weekly cut planner

Static single-file weekly meal planner for a 1940 kcal / 160P cut. Lives at: https://biglax.github.io/meal-prep/

- Drag & drop meals into the week (pointer events — works mouse AND touch)
- One-tap week generator (respects 👍/👎 ratings and favourites, avoids same-day duplicates)
- Macro targets tracked per day (kcal/protein/carbs/fat bars)
- Meal detail: ingredients (aisle-sorted) + dead-simple steps
- Auto shopping list from the planned week, checklist + copy to clipboard
- Weekly report + copy plan as text
- Add your own meals; ratings/favs persist in localStorage
